## 2. 产品目标
- 微信 + 抖音「趣味测评」小程序，**一套前端代码（uni-app）出双端**。
- 后端已定：Spring Boot 项目 `quiz-backend`，已部署上线。

## 3. 后端现状（已上线，可直接调）
- 技术栈：Spring Boot 4.1.1 / Java 17 / MyBatis-Plus 3.5.17 / MySQL（生产库名 `guiz`）/ H2（本地开发）。
- 部署：阿里云轻量服务器 + 宝塔；域名 `wangwang2.asia` 已 HTTPS；Nginx 反代到 jar(8080)。
- **当前唯一可用接口**：
  - 请求：`GET https://wangwang2.asia/api/quiz/random`
  - 返回 JSON：`{"id":1,"options":["宅家","出门浪","看剧","运动"],"title":"你更喜欢的放松方式？"}`
  - 含义：一道随机题 + 选项数组（目前只有 1 道种子题）。
- ⚠️ **目前只有这一个接口**。提交答案、算结果、用户登录等接口尚未开发（属后续里程碑），不要假设它们存在。

## 4. 已确定的架构约定（前后端都要遵守）
- 双端登录：微信 `wx.login`/`code2Session`、抖音 `tt.login`，统一映射 openid 到后端 user 表；用 JWT 鉴权。
- 微信特有功能（结果图云存储、订阅消息、内容安全）后续可能放微信云开发，与 Spring Boot 核心解耦；前端相关调用用 `#ifdef MP-WEIXIN` 隔离。
- 数据完全本地处理，不上传第三方（隐私承诺）。
- 小程序要求：请求域名必须 HTTPS 且加入对应平台「合法域名」白名单（微信公众平台 / 抖音开放平台）——`wangwang2.asia` 已配好 SSL，但别忘了在两个平台后台加白名单。

- 注意双端兼容（微信/抖音）与 uni-app 的请求封装（建议封装一个 `request.js`）。
