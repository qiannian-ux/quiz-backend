# 微信贴图号（小绿书）玩法手册 · 探我趣测版

> 2026-09-27 整理。目标是**用最低成本把小程序送进微信公域流量池**。
> 所有数字来自 2026 年的公开实操资料，平台规则会变，以你后台实际看到的为准。

---

## 一、先搞懂它是什么

微信 2026 年 2 月把公众号的「图文」正式更名独立为**贴图**（此前俗称「小绿书」），
形态 = **3:4 竖图 3-6 张 + 100~300 字短文案**，靠「看一看」信息流分发，本质是微信版小红书。

**和公众号最根本的区别**（决定了打法完全不同）：

| | 公众号图文 | 贴图号 |
|---|---|---|
| 发布 | 群发，有次数限制 | **无次数限制**，一天可发多条 |
| 流量来源 | 主要靠粉丝 + 私域 | **算法公域推荐**，与粉丝量关联度低 |
| 涨粉依赖 | 强 | 弱，零粉也能起量 |
| 定位 | 深度长文 | 视觉优先、碎片化 |

结论：**这是微信生态里唯一可以"靠铺量换曝光"的官方端口。**

## 二、平台硬规格（照着做，别自己发明）

| 项 | 值 |
|---|---|
| 图片比例 | **3:4 竖版，1080 × 1440px**。横图会被裁、方图展示区太小，天然吃亏 |
| 图片数量 | 3~6 张一组（也有实操 9-20 张，新手建议先 4 张） |
| 正文 | 100~300 字，太长没人看 |
| 黄金时段 | 11:30-13:00 / 17:30-20:00，次选 22:00-24:00 |
| 发布节奏 | 起号期每天 1 条；浏览破 1000 后每天 2 条；破 10000 再试 3-5 条 |
| 观察点 | **发布后 2 小时看第一次数据**；2 小时破 100 浏览 = 被推荐了 |

⚠️ **断更超过 3 天推荐量会断崖式下跌。建议先备 7 天稿再开始发第一条。**

## 三、冷启动：开号当天必须做的 4 件事

### 1）关掉「向朋友推荐我的内容」—— 这是最关键的一个开关

新手最常踩的坑：不关这个，内容**优先推给微信通讯录好友**，看起来有点赞有点阅读，
但全是熟人流量，**拿不到公域推荐、没有算法加权、涨不到精准粉**。

关掉之后内容才会被送进陌生公域流量池。**这是真正的冷启动开关。**

### 2）定位要极致细分，一句话讲得清

不要做「探我趣测」这种泛的。算法筛选的第一标准就是"你这个号到底是干嘛的"，
定位模糊**直接停止流量推送**。

建议方向（三选一，别贪多）：

- `MBTI 十六型观察日记` —— 每天拆一个类型
- `性格档案局` —— 测评 + 职场/恋爱场景
- `依恋型研究所` —— 只做恋爱依恋，最窄但最精准

账号名**要植入核心关键词**（如「MBTI」「依恋型」），方便搜索和算法识别。
简介别写"记录美好生活"，直白点明价值：「每天拆一个 MBTI 类型，测完就懂自己」。

### 3）头像、主页一次到位，之后别频繁改

每次改名字/简介，系统都要重新识别你的内容分类，**会掉权重**。想清楚再写。

### 4）备 7 条稿

用下面的内容公式，一口气写够 7 天的量再开跑。

## 四、内容公式：我们是「内容工厂」，这是最大优势

**别人做贴图号最痛苦的是想选题，我们的选题库是测评结果自动生成的。**

现有 5 套测评的结果数：MBTI 16 + DISC 4 + 九型 9 + 霍兰德 6 + 依恋 4 = **39 个结果**。
每个结果再乘以 3 个角度，就是 **100+ 条选题**，够发 4 个月：

| 角度 | 标题模板 |
|---|---|
| 是什么样 | `INFP 是什么样的人？三个特征，中两个就是你` |
| 场景代入 | `INFP 在恋爱里最常做的三件事，第三条扎心了` |
| 对比/搭配 | `INFP 和 ENTJ 为什么总互相吸引又互相折磨` |

### 一条贴图的标准结构（4 张图 + 1 段正文）

**图 1 · 封面（决定生死）**
信息流里用户只看到首图 + 标题，封面不行内容再好也没人点。
干货/知识类账号**大字海报样式辨识度最高**（红底白字、黄底黑字那一挂）。
避雷：画面模糊、色调暗沉、构图杂乱——用户一秒划走。

> 例：`INFP` 超大字 + 一行副标 `表面温和，内心戏多到爆炸`

**图 2 · 三个特征**（大字报，一眼扫完）

**图 3 · 一个场景**
"你有没有过这种时刻……" —— 让人对号入座，这是评论区留言的引子。

**图 4 · 引导 + 挂载**
`你是哪一型？点下面的链接测一测` + **发布时关联小程序**（不是在图里塞码）。

**正文 100-200 字**：首句钩子 → 场景描述 → 一句金句 → 引导点击链接。

⚠️ **算法偏好：真实场景 > 精美海报；互动率 > 曝光量。**
所以别把图做得像广告海报，做得像"有人真的这么想过"更有用。

## 五、转化：怎么把流量导回小程序

**用官方的「挂载小程序」能力，不要自己在图里塞二维码。**

- 贴图发布时支持直接关联微信小程序，用户点一下就进你的小程序。
- 这是**合规**的引流方式；正文/配图/评论区直接留手机号、个人微信、二维码是**高频违规，会限流降权**。
- 进阶：贴图号新建话题，认证为话题发起人后可以**在话题页置顶小程序链接**。

**飞轮（这是真正值得做的地方）**：

```
贴图号曝光 → 点挂载进小程序 → 测完生成结果海报 → 用户自己又发一条贴图 → 再曝光
```

所以**结果海报必须带品牌角标**（比如右下角一行小字「探我趣测」）。
用户每发一张，就是一张免费裂变海报，且 UGC 的信任度远高于你自己发的广告。

## 六、每天的操作清单（5 分钟）

1. 固定时段发 1 条
2. **发完立刻自己在评论区补一条引导性评论**（如"第三条太准了，是我本人"）
   —— 留言区广告需要 **≥4 条有效留言**才展示，而且评论热度是算法判断质量的重要信号
3. 2 小时后记一次数据：阅读、完读、转发
4. 把选题 / 标题 / 发布时间 / 数据记进一张表

**复盘规则**：连续一周单条阅读低于 50，问题在**封面和选题**，不是发布时间——先改封面别改时段。
不要用 2 小时的数据给账号判死刑，新号前几天没流量是正常的。

## 七、红线（踩了会限流甚至作废）

1. **不要搬运网图**。版权风险 + 系统查重会限制推荐。用自己生成的原创图。
2. **不要通篇硬广**。过度营销直接压低推荐流量。
3. **不要在正文/配图/评论区留联系方式和二维码**。走官方挂载。
4. **不要频繁改名改简介**，会掉权重。
5. **不要频繁批量删内容**。数据差就静置，批量删会触发风控。
6. **不要刷粉买评论**。刷出来的量触发不了自然推荐，还会被标记。
7. **不要断更超过 3 天**。

## 八、收益预期：别抱幻想

- 流量主：多数资料称 2026-03-20 起「100 粉开通」（原 500 粉，个人主体 + 实名）；
  **也有资料称尚未全量开放 —— 以后台「我 → 作品 → 贴图号主页」有没有入口为准。**
- 贴图广告主要在**留言区**，需 ≥4 条有效留言才展示。
- 实测约 **5-20 元/万阅读**（有博主实测 8-9 元），低于公众号长文的 30-50 元/万阅读。
- 多数人单日流量主收益也就几块到十几块。

**贴图号的价值是「引流到小程序」，不是广告分成。**
真正的钱在：小程序流量主（DAU≥50 后可开）+ 自愿打赏 + 未来小红书侧的商业化。
