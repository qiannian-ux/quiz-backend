## 0. 前置发现：微信「贴图号」= 第二条免费分发腿（2026-09-27）

> 这条不是新功能，是**新渠道**。它改变了上面所有功能排序的前提，所以放在最前面。

**是什么**：微信 2026-02 把公众号的「图文」正式更名并独立为「贴图」（此前俗称「小绿书」），
形态 = **3:4 大图 + 短文字**，视觉优先。所以你会觉得它和小红书像——它本来就是对标产物。

**为什么对我们是白捡的**：

| 契合点 | 说明 |
|---|---|
| 尺寸天然对齐 | 贴图原生 3:4 竖图，和我们要做的结果海报、和小红书封面**同一个比例**，一张图三处通用 |
| 可直接挂小程序 | 贴图支持关联微信小程序，点击直达——种草到转化的闭环**在微信内完成**，不用绕二维码 |
| 零粉也能起量 | 采用「发布」而非「群发」，不占群发次数，曝光靠算法推荐，**与粉丝量关联度低** |
| 发布无次数限制 | 不像公众号/服务号有额度，可以靠铺量换曝光 |
| 相册一键转贴图 | 微信 8.0.74 起，系统相册选中图片 → 分享 → 【分享为贴图】，两步直达编辑页 |
| 官方数据 | 首批贴图号平均阅读量比传统公众号图文高 3-5 倍，停留时长 +40% |

**最狠的一点：我们是「内容工厂」**。
5 套测评 × 每套若干结果 = 几十上百个结果，每个结果天然就是一条贴图选题
（「INFP 到底是什么样」「你的依恋型正在毁掉哪段关系」……）。
别人做贴图号最痛苦的是想选题，我们**选题库是自动生成的，边际成本为零**，
正好对上贴图号「靠铺量换曝光」的玩法。

**待你亲自确认的一件事**（30 秒）：
打开微信 → 我 → 作品 → 贴图号主页，看有没有「流量主」入口。
网上资料冲突：多数 2026 年资料称已开放且 **2026-03-20 起全面执行「100 粉开通流量主」**
（取代原 500 粉，个人主体 + 实名即可）；也有资料称尚未全量开放。
**以后台实际有没有入口为准。**

**收益预期（别抱幻想）**：贴图广告主要在**留言区**，且需 ≥4 条有效留言才展示；
实测万次阅读约 5-20 元（有博主实测 8-9 元），低于公众号长文的 30-50 元/万阅读。
贴图号的价值在**引流到小程序**，不在广告分成本身。

**红线**：正文/配图/评论区不要直接留手机号、个人微信、二维码（高频违规，会限流降权）。
要引流就用官方的「挂载小程序」能力，别自己在图里塞码。

## 第一档 · 立刻做（低成本，直接补现在的短板）

### 1. 结果海报分享图 ★最高优先级

- **做什么**：结果页加一个「保存分享图」按钮，canvas 现画一张 3:4 竖图，
  内容 = 结果码大字 + 一句人话解读 + 维度条形图 + 小程序码，存进相册。
- **为什么值**：这是**目前链条上缺的最后一环**。你定的策略是「利润靠小红书，小程序只做免费钩子」，
  但用户测完拿不到一张能发小红书的图 —— 钩子就断了。其他功能都是加分，这个是通路。
- **成本**：纯前端，1~2 个文件，不动后端、不动数据库。
- **技术要点**：
  - `uni.createCanvasContext` 画，再 `uni.canvasToTempFilePath` → `uni.saveImageToPhotosAlbum`。
  - 小程序码用微信 `getUnlimitedQRCode`（B 接口）后端生成一次存 OSS/云存储，前端按 `scene` 取；
    抖音端没有等价物，降级成「纯文字卡片 + 分享文案」。
  - 拒绝授权相册时不要弹错误，改成「长按图片保存」兜底。
- **怎么删**：删 `components/result-poster/` 一个目录 + 结果页上那个按钮。

### 3. 我的测评档案（历史记录 + 变化曲线）

- **做什么**：「我的」页加一个档案入口，列出测过的每一次（测评名 / 结果 / 时间），
  同一套测多次时画一条变化曲线（MBTI 四个维度的百分比漂移）。
- **为什么值**：廉价地制造**回访理由**——"三个月后我再测一次看看变了没"，
  是所有性格测评 App 留存的核心机制。数据层 `user_quiz_record` 已经落了，只差展示。
- **成本**：后端 1 个查询接口 + 前端 1 个页面，无新表。

## 第二档 · 有日活再做（吃流量，放大传播）

### 4. 双人契合度对比

- **做什么**：做完恋爱依恋 / MBTI 后生成一张「邀请卡」，对方扫码做完，
  两边结果拼一页：契合点、摩擦点、一句相处建议。
- **为什么值**：人格类内容天然是**双人传播**的，一个人测完会拉另一个人，
  这是把单次分享变二次传播的最低成本方式。恋爱依恋量表已在库里，不用造内容。
- **成本**：中。需要一个「配对码 / 配对记录」的轻量存储（云开发或 `user_quiz_record` 扩字段）。
- **坑**：别做「必须配对才能看结果」——那就是付费墙的变体，违反硬约束 ②。
  单人结果照常完整给出，配对只是**额外的**一页。
- **怎么删**：云函数 + 一个页面，独立边界。

### 5. 流量主广告位

- **做什么**：结果页底部 + 首页列表间隔插 banner / 激励视频（激励视频给"多看一段解读"这种非必要奖励）。
- **为什么值**：唯一的营收来源。**门槛：DAU ≥ 50 + 已上线 + 类目合规**，现在还开不了。
- **坑**：广告绝不能挡在结果前面（硬约束 ③）；激励视频的奖励必须是锦上添花，不能是本该免费的内容。
- **怎么删**：后台关掉广告位即可，代码侧是配置开关。

### 6. 每日心情打卡（接天气卡）

- **做什么**：天气卡下面加一行「今天心情」五个表情，点一下记一笔，攒够天数解锁一句回顾。
- **为什么值**：天气卡目前是「一次性展示」，没有回访钩子。加打卡后变成**每天都有理由打开**。
  登录天数已落库，复用即可。
- **成本**：低。1 张表（或复用 `user_login_day` 的扩展）+ 一个组件。
- **怎么删**：组件 + 接口，独立。

## 第三档 · 简历加分（架构向，慢工）

### 7. AI 深度解读

- **做什么**：结果页「AI 深度解读」按钮 → 后端调 LLM，按 `basic_report` + 用户具体得分生成
  一段 300 字左右的个性化解读，异步生成 + 按 (quiz, 结果码) 缓存复用。
- **为什么值**：这是你项目重心里写着的 **LLM** 那一支，也是和市面上一堆 MBTI 小程序的**差异化**。
- **成本**：中高。要处理超时、限流、敏感词、缓存、降级（AI 挂了就只显示原报告，绝不报错页）。
- **坑**：① key 只进生产配置，绝不进前端；② 结果不缓存用户隐私，只按结果码缓；
  ③ **AI 解读不能变成「免费只有一句，完整版要钱」**。
- **怎么删**：`feature.ai.enabled` 开关。

### 8. 云开发排行榜 / 好友 PK

- **做什么**：微信云函数聚合匿名统计——"和你同型的人里 62% 也选了…"、"全国 INFP 占比排行"。
- **为什么值**：落地你笔记里「微信云开发解耦示范」这一支，简历上能写
  「主后端 Spring Boot + 边缘能力云函数，通过开关解耦、可整体摘除」。
- **成本**：中。云函数 + 云数据库的免费额度够个人项目用。
- **怎么删**：`feature.cloud.enabled` 关掉即降级为不显示，no-op 兜底（这条规则你早就定了）。

### 9. 管理后台（admin）

- **做什么**：`https://wangwang2.asia/admin.html`，题库增删改查 + 数据看板（日活 / 完测率 / 各测评分布）。
- **为什么值**：省掉你每次改文案都要写 SQL 的成本；看板数据也是简历上的量化素材。
- **⚠️ 前提**：**必须先做鉴权**（管理员口令 + 服务端 session + 接口拦截），
  否则等于把一个公开的数据库管理页挂在公网上——这是这个项目目前**唯一真实的安全敞口**。
- **成本**：中高。建议排在 AI 之后。
