## 前端已就绪项（你只需实现后端 + 后台配置）

- `utils/payment.js`：`buyProduct(productId)` 拉起支付，`checkIosVersion()` iOS≥8.0.68 校验。
- `pages/result/result.vue`：「¥5.9 解锁全站测评」按钮（unlock_all）+「请作者喝奶茶」打赏按钮（tip_milktea）。
- 两个按钮都已 `// #ifdef MP-WEIXIN` 条件编译包裹，抖音端不显示。

## 后端待办（你实现）

1. `POST /api/pay/order` — 下单签名（§4）
2. `POST /pay/notify` — 发货推送验签 + 幂等 + 发货（§5，拦截器白名单放行）
3. `POST /api/pay/query` — 兜底查单（§6）
4. 新建 `pay_order` 表（§7）
5. MP 后台：道具管理建 `unlock_all`(¥5.9) / `tip_milktea`(¥6.0) 并发布
6. MP 后台：消息推送 + 发货推送 URL 配置（§5、§6）
